```

```

```

```

```
"Maya Angelou once said, 'There is no greater agony than bearing an untold story inside you.' This profound wisdom speaks to the human need for expression and connection. Her words remind us that our experiences, when shared, have the power to heal and inspire others."
```

```

```

1. Copy any prompt above

4. The system will automatically detect the content type and emotional tone
5. Appropriate voice settings, visual effects, and timing will be applied

Each prompt is designed to naturally trigger the content analysis system without forcing keywords.
