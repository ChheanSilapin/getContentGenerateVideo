# Video Generator Features

## Content Creation
- Converts text to speech with natural-sounding audio
- Creates slideshow videos from images with professional effects
- Generates synchronized subtitles automatically
- Merges video and subtitles into a final output

## Image Sources
- Downloads images from websites (web scraping)
- Uses local images from your computer
- Allows selection of specific images

## Video Customization
- Supports multiple aspect ratios (9:16 vertical, 16:9 horizontal, 1:1 square)
- Applies visual enhancements (color correction, contrast, brightness, saturation)
- Adds dynamic effects (zoom, fade transitions)
- Adjusts framing and composition

## Audio Options
- Generates speech from text
- Enhances audio quality
- Adjusts volume levels

## Processing Options
- CPU or GPU processing selection
- FFmpeg integration for video encoding

## Interface Options
- Full graphical user interface with tabs for different functions
- Console mode (limited implementation)
- Progress tracking and logging

## Batch Processing
- Handles multiple videos in sequence
- Processes batches of content

## Output Control
- Customizable output directory
- Creates backup of original videos
- Supports different subtitle formats

## Technical Foundation
- Modular MVC architecture
- Specialized services for audio, image, video, and subtitle processing
- Threading model for responsive UI during processing
- Stop mechanism for cancelling generation
