## 🚀 Quick Start Guide

### Basic Video Creation (3 Steps)
1. **Input Tab**: Enter your text and select image source
2. **Images Tab**: Preview and select your favorite images
3. **Input Tab**: Click "Generate Video" 

Your video will be created with voice-over, subtitles, and professional effects!

### Installation & Setup
1. Download and run the installer
2. Launch "Video Generator"
3. No additional setup required - FFmpeg is bundled!

## 📑 Tab-by-Tab Usage

### 🎯 **Input Tab** - Main Video Creation
**Purpose**: Create videos from text with various image sources

#### How to Use:
1. **Enter Text**: Type your script in the text box
   - ✅ Supports any length (automatic optimization for long text)
   - ✅ Unicode and emoji support
   - ✅ Automatic speech timing

2. **Choose Image Source**:
   - **Website URL**: Enter any website URL to download images
   - **Local Folder**: Browse to select folder with your images
   - **Selected Images**: Use images from the Images tab

3. **Configure Options**:
   - **Processing**: CPU (recommended) or GPU
   - **Output Folder**: Set custom save location or use default

4. **Generate**: Click "Generate Video" and monitor progress

#### Supported Image Sources:
- ✅ Any website with images
- ✅ Local image folders
- ✅ Individual image selection
- ✅ Popular sites: Unsplash, Pexels, Pixabay
- ⚠️ Smart blocking for problematic sites (Facebook, Instagram, etc.)

---

### 🖼️ **Images Tab** - Preview & Selection
**Purpose**: Preview downloaded images and select specific ones for your video

#### How to Use:
1. **Download from URL Pinterest or WordPress only**:
   - Enter website URL
   - Click "Download Images"
   - Wait for preview to load

2. **Browse Local Images**:
   - Click "Browse Local Folder"
   - Select folder containing images
   - Preview will show all compatible images

3. **Select Images**:
   - ✅ Check/uncheck images you want
   - 🗑️ Use "Clear Selection" to start over
   - 📱 Thumbnail preview with selection status

4. **Use Selected**: Return to Input tab and generate with selected images

#### Supported Formats:
- JPG, JPEG, PNG, GIF, WEBP, BMP
- Automatic format conversion if needed
- Smart filtering (skips icons, logos, tiny images)

---

### 🎬 **Video Tab** - Multi-Video Processing
**Purpose**: Add voice-over and subtitles to existing video files

#### How to Use:
1. **Add Video Entries**:
   - Click "➕ Add Video" for each video
   - Browse to select video file
   - Enter voice-over prompt for each

2. **Configure Audio Settings**:
   - **Mute Original**: Replace original audio entirely
   - **Volume Control**: Mix with original audio (0-100%)

3. **Generate All**: Click "🚀 Generate All Videos"
   - Processes all entries in sequence
   - Automatic cleanup keeps only final outputs
   - Progress tracking for each video

#### Supported Video Formats:
- MP4, AVI, MOV, MKV, WMV, FLV, WEBM
- Preserves original video duration
- Maintains original video quality

#### Audio Mixing Options:
- **Voice-over Only**: Mute original audio completely
- **Mixed Audio**: Blend voice-over with original (adjustable volume)
- **Smart Timing**: Voice-over synced to video duration

### 📦 **Batch Tab** - Multiple Video Processing
**Purpose**: Process multiple different projects in sequence

#### How to Use:
1. **Add Jobs**:
   - Configure video in Input tab
   - Click "Add Current Settings as Job"
   - Repeat for different projects

2. **Cleanup Options**:
   - ✅ **Auto-cleanup**: Keep only final_output.mp4 (recommended)
   - 📁 **Keep Debug Files**: Retain intermediate files for troubleshooting
   - 💾 **Space Saving**: Typically 60-80% disk space reduction

3. **Process Batch**: Click "Start Batch Processing"
   - All jobs processed automatically
   - Individual progress tracking
   - Automatic cleanup per preferences

#### Batch Benefits:
- 🕒 Set up multiple projects and run overnight
- 🧹 Automatic file management
- 📊 Comprehensive progress tracking
- 🎯 Perfect for content creators with multiple videos

## 🛠️ Troubleshooting

### ❌ **Common Issues & Solutions**

#### "No images found from URL"
- ✅ Try different websites (Unsplash, Pexels work great)
- ✅ Avoid social media sites (Facebook, Instagram blocked)
- ✅ Check if URL contains actual images

#### "Voice-over failed to add"
- ✅ Ensure text is not empty
- ✅ Check that video file is not corrupted
- ✅ Try shorter text for testing

#### "Output folder not found"
- ✅ Use Browse button to select valid folder
- ✅ Ensure you have write permissions
- ✅ Reset to default if custom folder fails

#### "Process stopped unexpectedly"
- ✅ Check available disk space
- ✅ Close other video applications
- ✅ Try CPU processing instead of GPU

### 📋 **Getting Help**
- Check the Log tab for detailed error messages
- Try the same operation with smaller/simpler content first
- Use default settings if custom settings cause issues
- Enable debug file retention to analyze intermediate files
